# 🎮 Aventura Matemágica

**Aventura Matemágica** é um jogo educativo 2D desenvolvido no Unity, voltado para estudantes do **6º ano do Ensino Fundamental**. O jogo combina exploração, desafios e questões de matemática de forma divertida e interativa.

---

## 🛠️ Tecnologias utilizadas

* **Unity 6000.5.7f1**
* **C#**
* **Visual Studio**
* **Unity Hub**
* Projeto desenvolvido em **2D**

---

## 💻 Requisitos

Antes de executar o projeto, certifique-se de ter:

* Windows 10 ou superior
* Unity Hub instalado
* **Unity 6000.5.7f1** instalado
* Visual Studio instalado
* Suporte para desenvolvimento em C# configurado no Visual Studio
* Espaço disponível para armazenar o projeto

> ⚠️ É recomendado utilizar exatamente a versão **Unity 6000.5.7f1** para evitar problemas de compatibilidade.

---

# 🚀 Como executar o projeto

## 1. Baixe o projeto

Baixe ou clone o repositório completo do jogo para o seu computador.

Se estiver utilizando o GitHub, você pode clicar em **Code → Download ZIP** e extrair a pasta.

---

## 2. Abra o Unity Hub

Abra o **Unity Hub** no computador.

Na tela inicial, selecione:

**Projects → Add → Add project from disk**

Depois, localize a pasta do projeto que foi baixada.

> 📁 Selecione a **pasta principal do projeto**, onde estão as pastas `Assets`, `Packages` e `ProjectSettings`.

---

## 3. Abra o projeto

Depois de adicionar o projeto ao Unity Hub, clique sobre ele para abrir.

Como o projeto foi desenvolvido utilizando a versão:

**Unity 6000.5.7f1**

pode aparecer uma mensagem solicitando a instalação ou confirmação dessa versão.

Utilize a versão indicada para garantir o funcionamento correto do projeto.

⏳ Na primeira abertura, o Unity pode levar alguns minutos para carregar e importar os arquivos.

---

# 🎮 Executando o jogo

Depois que o projeto estiver aberto no Unity:

1. No painel **Project**, localize a pasta onde estão as cenas do jogo.
2. Abra a cena:

**`Entrada do Jogo`**

3. Verifique se essa é a cena carregada na janela **Hierarchy**.
4. Clique no botão **▶ Play**, localizado na parte superior do Unity.

O jogo será iniciado diretamente pela tela inicial.

A primeira tela do jogo corresponde ao:

**Cenário 1**

# 🧭 Estrutura básica do projeto

O projeto possui, principalmente:

```text
Aventura Matemágica/
│
├── Assets/
│   ├── Cenas/
│   ├── Scripts/
│   ├── Imagens/
│   ├── Sprites/
│   ├── Áudios/
│   └── ...
│
├── Packages/
│
└── ProjectSettings/
```

### 📂 Assets

Contém os principais arquivos utilizados no desenvolvimento do jogo, como cenas, scripts, imagens, sprites e áudios.

### 📂 Scripts

Contém os códigos desenvolvidos em **C#**, responsáveis pelo funcionamento das mecânicas do jogo.

### 📂 Scenes

Contém as diferentes cenas e fases do jogo.

### 📂 Packages

Contém os pacotes e recursos utilizados pelo Unity.

### 📂 ProjectSettings

Contém as configurações gerais do projeto.

---

# 💻 Visual Studio

Os scripts do jogo foram desenvolvidos em **C#** utilizando o **Visual Studio**.

Caso seja necessário editar algum código:

1. Abra o arquivo `.cs` dentro do Unity.
2. O Visual Studio será utilizado para editar o código.
3. Salve as alterações.
4. Retorne ao Unity e aguarde a atualização dos scripts.

> ⚠️ Não é necessário abrir o Visual Studio manualmente para simplesmente jogar. Ele é utilizado principalmente para visualizar ou modificar os códigos do projeto.

# ⚠️ Possíveis problemas

### O projeto não abre

Verifique se está utilizando a versão:

**Unity 6000.5.7f1**

Também confira se você selecionou a pasta principal do projeto, contendo `Assets`, `Packages` e `ProjectSettings`.

### As imagens não carregam

Execute o comando git lfs pull.

### Os scripts apresentam erros

Verifique se o Visual Studio e o suporte para **C#** estão instalados corretamente.

Também aguarde o Unity terminar de importar todos os arquivos antes de executar o projeto.

### O jogo começa em uma cena diferente

Abra manualmente a cena:

**`Entrada do Jogo`**

e clique em **▶ Play**.
